How I Build AI Products

  1. Define the problem and success metrics before choosing a model
  2. Spec-driven development: contracts, acceptance criteria, and data maps before build
  3. Prefer RAG and retrieval quality work before defaulting to fine-tuning
  4. Layer guardrails, validation rules, and compliance checks before full automation
  5. Run evals and accuracy validation (offline suites + production monitors)
  6. Embed Human-in-the-Loop where stakes, ambiguity, or regulation require it
  7. Separate AI quality metrics from core product KPIs—both matter
  8. Ship MVP → measure → tighten evals → expand autonomy
